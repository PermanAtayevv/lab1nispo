## Запуск проекта задания 4

Из корня репозитория с исходниками:

```powershell
cd task4/compose
docker compose up -d --build --wait
```

Приложение: http://localhost:8080, документация API: http://localhost:8080/docs.

Остановка с сохранением данных: `docker compose down`.

В этот комплект входят отчёт и изображения. Исходники task1–task4 нужно сохранить из выполненного проекта; комплект не заменяет их.
